# SOP Tahfidz SDIT Nusantara

Dokumen sintetis untuk uji WS-1 (b). Bukan SOP resmi sekolah mana pun.

## Setoran hafalan

Setoran hafalan minimal 5 ayat per pertemuan. Guru tahfidz mencatat setiap setoran di menu Al-Quran AlurSekolah pada hari yang sama.

## Murojaah

Murojaah dilakukan setiap Jumat untuk hafalan satu pekan terakhir. Murid yang belum lancar mengulang setoran pada pertemuan berikutnya.

## Ujian kenaikan juz

Ujian kenaikan juz diajukan wali kelas setelah murid menyelesaikan satu juz. Penguji adalah koordinator tahfidz.
