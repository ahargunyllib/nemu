# BPMN processes are walked in code; the model only fills slots

An uploaded BPMN 2.0 file (AlurKerja Studio exports the Camunda 7 dialect) is parsed with `bpmn-moddle` into tasks, lanes, form fields and gateway conditions, and Nemu walks it deterministically: JUEL `${…}` conditions are evaluated with Jexl and FEEL with feelin, a condition that needs a value the teacher hasn't given becomes one question, and a task outside the teacher's lane ends the walk after the teacher's Ajukan. One model call turns the teacher's sentence ("izin Kamis, anak sakit") into slot values, constrained to the form's own options, with a calendar table so it never does date arithmetic. This supersedes ADR-0006's "no BPMN runtime" for the school workspace: the PRD's promise that a new process needs no new code only holds if the process file itself drives the guidance. The plan is stateless like the rest of the Service (ADR-0004): the client sends back the slots and step index. A flow drawn with only a label cannot be evaluated and is reported as an import warning.
