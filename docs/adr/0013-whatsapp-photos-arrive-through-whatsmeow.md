# WhatsApp photos arrive through whatsmeow on the team VPS

Teachers send grade-book photos to the Nemu WhatsApp number. The plan was Meta's Cloud API webhook, but its test number takes hours to set up, allows only five verified phones, and charges for replies beyond the free tier. We chose whatsmeow, an unofficial WhatsApp Web client, in `apps/wa-bot` on the team VPS (`infra/`), knowing it breaks WhatsApp's terms and the number may be banned. To lower that risk, the number is a dedicated one, unknown senders are ignored without a read receipt, and the bot handles one message at a time with random pauses and a typing indicator before each reply. Because it can't receive webhooks from the Worker's side, the bot calls two Nemu Service endpoints with a shared secret (`WA_BOT_SECRET`): a sender check before any download, then the photo hand-off to `enqueuePhoto`, which checks the sender again. Replies are free with whatsmeow, so the bot confirms each photo in Indonesian. If the number is banned, the QR upload page (`inboxUploadPhoto`) still works, and moving to the Cloud API replaces only the bot.
