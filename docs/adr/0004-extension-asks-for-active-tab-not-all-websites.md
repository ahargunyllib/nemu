# The extension asks for activeTab, not all websites

Government IT teams refuse an extension that Chrome installs with "read and change all your data on all websites", which `<all_urls>` triggers. The Nemu Extension therefore asks for host permissions on the Nemu Service and the Demo App origins only, plus `activeTab`. The cost is the Area Crop: `captureVisibleTab` needs `<all_urls>` or an `activeTab` grant, and a host permission for the page isn't enough. Chrome grants `activeTab` only when the toolbar icon or the shortcut fires the action on that tab, until the tab navigates away. So the Area Crop works once Rina has opened Nemu that way on the tab, and fails when the Composer was opened only from the mascot or in Arc, which fires the action without a tab. The failure tells Rina, in the Kartu area, to open Nemu from the toolbar icon or Ctrl+Shift+Space and select again.

We considered keeping `<all_urls>` for the demo (QA and IT refuse it) and requesting `<all_urls>` as an optional permission the first time the Area Crop is used (the same warning, just later, and another prompt mid-question). On a page outside the allowlist the toolbar icon opens a popup, "Nemu aktif di AlurKerja", with a button to the Demo App: the manifest sets it as the action's default popup, and the background clears it on Demo App tabs, where the action has to fire to grant `activeTab`.
