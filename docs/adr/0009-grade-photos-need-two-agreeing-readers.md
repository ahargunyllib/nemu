# Grade photos need two agreeing readers before a cell is accepted

A handwritten grade-book cell is accepted without asking the teacher only when two vision models from different families read the same value and code finds nothing doubtful (struck out, initialed, a 0, out of range, far from the rest of the column). Every other cell is re-read from a crop and becomes a verification question, with the readings as unselected options. We did not trust a single model's confidence: none of the strong models on OpenRouter return logprobs, published handwriting benchmarks stay at 80–84% on forms, and the dominant errors (blanks filled in, names "corrected" to likely spellings) are made with high confidence. The roster is never in the reading prompt, so names are transcribed, not snapped to the class list; matching happens in code, and any spelling difference is confirmed by the teacher, as the PRD's verification step expects. The cost is two reads per page; the cheaper model pair is a configuration change once real token counts are measured.
